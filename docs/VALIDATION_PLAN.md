# 私教工作室学员经营试点计划

目标是判断老板是否愿意为“可执行的学员跟进与可核对的结果”持续付费。当前首批客群假设为成人力量与体能私教工作室，详细定位见 [产品方向](PRODUCT.md)。以下数量和门槛是团队实验标准，尚无客户验证结果。软件实现与本地自动验收见 [当前产品范围](PRODUCT.md) 和 [验收说明](ACCEPTANCE.md)。

## 当前阶段与投入边界

已确认暂时没有现成客户。首要商业任务仍是取得真实经营负责人的反馈和试跑承诺；成人力量与体能工作室是初始招募假设，不能因文档完整或代码可运行就视为市场已验证。按用户要求，本地真实账号、共享组织、学员负责关系、跟进、订单核验、履约与原生微信小程序已经实现，现阶段可以用实际产品验证工作流。AI、复杂家长服务和加盟财务不扩展为当前购买主线。

先用一次短周期招募取得下一步证据。首次触达或筛选不到客户时，分别检查名单是否匹配、能否找到负责人、邀请表达和触达方式，不直接把没有回复当作没有需求。初始渠道只是待测试的方法，不假设已拥有渠道优势。

## 首轮招募行动

选择一个便于实地拜访或远程沟通的城市，先做约 30 家候选门店的手工清单。城市尚未确定，不把示例门店所在城市当作创始团队所在地。名单按公开业务类型筛选成人力量与体能私教工作室，记录公开业务入口、是否找到经营负责人、触达方式、回复、访谈和下一步承诺。

可以测试实地预约、公开商家业务入口、同行引荐或经营者主动参与的讨论渠道。仅使用合适的业务联系渠道，不自动群发或以学员咨询身份套取经营资料。本文是执行准备，不表示已联系门店。

| 步骤 | 目标与产物 |
| --- | --- |
| 建立候选清单 | 约 30 家同类门店；写明筛选理由，避免把普通健身会员或受雇教练算作采购负责人 |
| 取得初步访谈 | 争取约 8 次经营负责人访谈；记录触达和回复，不把过程目标当作预期转化率 |
| 核对真实问题 | 至少 3 家愿用脱敏案例展示当前处理方式；比较是否出现同类、反复、已有成本的问题 |
| 取得下一步承诺 | 至少 1 家明确指定负责人、可核验样例范围和试跑时间；“有空再聊”不算承诺 |
| 决定继续投入 | 有重复问题和具体试跑安排后，继续人工流程实验；3 家试点是后续招募目标，不是当前已有资源 |

这些数量是行动目标，不是统计结论，也不是单次未达标即否决的门槛。投入前约定本轮可用工时和复盘点，记录实际获客与支持成本；若负责人反馈普遍已有有效方案或不愿继续，重新审查购买理由。

## 访谈邀请草稿

> 您好，我们正在了解私教工作室平时如何处理学员停练、课包快到期和续课跟进。想请实际经营负责人聊 20 分钟，了解现有做法，不需要提供学员姓名或电话，也不用更换系统。如果问题匹配，再约一次用少量脱敏案例做手工整理。请问您是否愿意参与？

邀请先说明调研目的，访谈先看最近的实际案例，再展示一张“原因、负责人、下一步、结果”的样例清单。可以展示当前本地产品的真实账号、学员分配、联系和续费核验流程；演示数据应由讲解者明确建立，并说明尚未获得市场或效果验证。不能把未实现的导入、AI 或微信支付展示为已交付能力。

## 后续客户招募

先接触 8–12 位符合条件、实际参与经营决策的老板，补充 3–5 位日常带固定学员的教练。记录门店数、收费方式、学员负责关系、现用软件、数据可取得方式和采购决定人。优先同一城市、同一服务模式，减少差异导致的交付负担。

客户需要允许以最少数据查看近期停练或到期未续案例，并愿意指定试点负责人。仅表示“功能不错”不算有效需求；不具备授权的数据不导入。若现有资源主要来自少儿机构或加盟总部，先重新比较其可接触性、业务材料和付费承诺，不机械执行成人客群假设。

## 访谈要取得的证据

| 问题 | 需要看的事实 |
| --- | --- |
| 最近三个停练或到期未续学员，如何被发现 | 当时的到课、权益、负责教练和发现时间 |
| 后续谁联系、联系几次、结果怎样 | 实际沟通或跟进记录，能否复原下一次行动 |
| 现有软件已经提醒什么，为何仍有遗漏 | 当前提醒、任务列表和实际工作路径 |
| 老板如何判断跟进是否完成 | 现用表格、会议和汇报；是否必须重复录入 |
| 学员不续的主要原因是什么 | 客户反馈与员工推断分别记录，不把未续都归因于失联 |
| 获得可靠数据要付出什么成本 | 导出权限、字段、更新频率、历史覆盖和人工工时 |
| 当前每周花多少时间，谁承担预算 | 实际任务、参与人、可接受的付费范围和采购流程 |

最后展示一份包含原因、负责人、下一步和结果的样例名单，请对方用真实案例判断哪里有用、哪里多余。先不询问是否需要“AI 流失预测”，也不要求对方对未使用的软件承诺提高多少续费率。

## 两周工作流实验

招募 3 家愿意提供授权数据的试点。可在客户认可的人工表格或当前本地组织版本中试跑。旧固定身份 Sites 示例站点不用于承接真实经营数据；本地组织只录入已获授权的必要资料。若采用人工流程，仍需限制可见人员、记录来源与约定退出处理。当前没有通用导入/导出和撤权管理界面，不能承诺已经自动完成。

| 时间 | 工作 | 验证点 |
| --- | --- | --- |
| 第 1–2 天 | 确认数据授权和范围，取得近期到课、余额、负责关系，记录现用处理流程 | 能否取得足够数据，历史覆盖能否支撑判断 |
| 第 3–5 天 | 人工生成少量名单，由店长逐条确认，再分配教练 | 是否真需要行动，是否知道该采取什么动作 |
| 第 6–10 天 | 记录联系、下一次行动、暂停原因和重新到课 | 是否持续执行，是否产生重复录入或骚扰风险 |
| 第 11–14 天 | 汇总使用与负担，给出明确范围、价格和支持方式的后续报价 | 客户是否愿为已经用过的工作流付费继续 |

并行试点应先约定唯一的权益、出勤和订单权威来源。当前本地版能独立开卡、预约和扣课，但尚未实现来源映射、导入快照或原系统同步。若客户继续以原系统为权威，先用人工核对限定试跑范围，不在两套账中重复扣课；自动导入和核验适配是后续需求，不能当作现成能力。

试点复核每条信号的数据覆盖。当前本地规则依据实际课包和履约记录，任务保留创建/更新时间；没有导入覆盖识别、可配置阈值和暂停/拒绝联系抑制功能。店长先复核任务并手工尊重暂停或不联系意愿，不把缺记录当作没来。AI 草稿尚未实现，当前由员工自行撰写与发送联系内容。

首轮保留统一的最小交付范围。若需要人工整理名单、复核结果或定制导入，分别记录工时；只有软件自动完成的部分才计为产品节省的工作量。

## 指标口径

| 指标 | 定义 |
| --- | --- |
| 数据可用率 | 人工或后续导入校验后可用于规则的学员记录数 ÷ 本次获授权范围记录数；缺字段、超出覆盖和冲突分别列出，当前需人工统计 |
| 信号认可情况 | 店长认为需行动、无需行动和无法判断的数量分别列示，不把未知归为正确 |
| 按时处理率 | 确认后的到期跟进项中，截止前记录有效动作的数量 ÷ 本期应处理项；仅点击完成不算动作 |
| 跟进负担 | 老板与教练每周导入、复核、录入、联系和汇总的工时，区分软件和人工服务 |
| 关联后恢复到课 | 已确认需召回学员中，首次跟进后固定观察窗内实际完成训练的去重人数；预约未履约单列 |
| 已核验续费 | 当前系统结案须关联同学员在跟进创建后登记的有效已付款订单；实际付款由门店核对线下凭证，退款和口头承诺分别处理 |
| 到期群体续费率 | 事先确定的同类到期学员中，固定观察窗内完成已核验续费的人数 ÷ 到期群体人数；不随结果变更群体 |
| 继续付费 | 对明确套餐和价格接受付费继续的门店数，口头兴趣与实际付款区分 |
| 单店交付成本 | 软件、模型、导入实施和人工支持成本之和；记录一次性与经常性成本 |

跟进和续费存在关联不代表续费由产品促成。若要评估增量，应在可行时预先设置同类学员分组或分阶段启用，保持其他服务条件可比。不能拒绝应有服务来制造对照；小样本只作为方向信号，不给出效果保证。

## 更长周期的结果观察

在愿意继续的门店观察一个完整权益决策周期，初拟 6–8 周，周期较长时相应延长。实验开始前写明到期群体、恢复到课的观察窗口、暂停和已知离店等处理方式，以及订单与退款核验来源。

两周结束只决定是否继续投入。没有覆盖真实续费机会的样本，不用续费率判断产品失败，也不能用短期预约增长宣称续费成功。

## 继续与停止条件

暂定继续条件：3 家试点至少 2 家持续每周处理名单并提供结果记录，且至少 2 家按明确价格实际付费继续；数据路径和支持成本可重复。本地共享组织、学员分配、规则待办、行动及订单核验结果已实现；达到上述条件后，优先根据实际重复成本决定是否开发授权导入、来源映射及必要报表，再评估扩展。

出现以下情况先停止扩展并定位原因：

- 老板原来已能有效处理名单，新增工作台没有节省时间或改善执行。
- 教练无法持续录入，或重复维护两个系统的成本高于收益。
- 原软件已满足同样任务，切换和额外付费的理由不足。
- 数据无法可靠、持续取得，导致大部分信号不能判断。
- 业务主要问题是课程供给、服务质量或价格，跟进工具无法改变关键结果。
- 客户愿意买高强度人工代运营，却不愿单独买软件；应重新定义商业模式。

转向少儿体育须先看到机构持续组织反馈、家长确实使用和付费承诺；转向加盟清分须取得实际结算样例、规则、专人和付费试点；转向个人教练须确认其独立经营权和可重复触达渠道。每次只验证一条购买主线。
