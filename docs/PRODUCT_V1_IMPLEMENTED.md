# 历史四端体验版与当前实现迁移

原四端 HTML 原型曾形成一个私有业务体验版：平台、总部、门店/教练与学员端，用预置身份和示例数据展示排课、预约冻结、签到消课、跨店内部记账与总部任务。

该阶段采用拥有者独立空间、单行 JSON CAS、Cloudflare D1 和托管认证。其截图、固定身份、示例卡片与旧 D1 集成测试只属于历史体验版，不是当前真实账号版本的开通资料或验收结果。

2026 年 10 月 24 日，本地实现已替换默认运行入口：

| 原体验资产 | 当前状态 |
| --- | --- |
| 按登录拥有者复制示例空间 | Node + SQLite 共享组织业务数据；空库首次 setup |
| 固定 persona 角色切换 | 独立用户、持久化 memberships、仅已有授权切换 |
| 示例学员和课包 | 真实建档、负责教练、线下凭证开卡/续费订单 |
| 冻结、签到、消课领域规则 | 保留并通过真实 HTTP/SQLite 事务验证 |
| 基础课程和门店视觉 | 保留，补齐代约、停课、迟取消、未到店等入口 |
| 简单操作轨迹 | 追加式审计、课时流水、订单及反馈存储 |
| 总部任务 | 保留通用协同；另建学员跟进、教练分配和结果核验 |
| 内部跨店单据 | 保留并保存金额依据，仍不执行资金支付 |
| 响应式学员网页 | 保留，并新增独立原生微信小程序 |

当前范围以 [PRODUCT.md](PRODUCT.md)、[ARCHITECTURE.md](ARCHITECTURE.md)、[LOCAL_RUN.md](LOCAL_RUN.md) 和 [ACCEPTANCE.md](ACCEPTANCE.md) 为准。原 HTML 设计与竞品调研文件继续作为设计输入保留。

本次没有更新旧 Sites 站点、部署后端或发布微信小程序。历史托管脚手架与 `*:legacy` 命令仍在仓库中，但不属于默认运行与验收路径。
