# 练多多

## 产品使用说明

练多多帮助独立教练、私教工作室和连锁门店管理学员、课包、排课、预约与授课结算。独立教练无需门店即可使用；门店团队可按已有授权协作，同一微信可保留教练和学员身份。

### 管理员：建立门店并邀请团队

1. 登录后台；有多个工作空间时，在顶部切换到需要管理的组织或门店。
2. 在「门店管理」建立门店，在「教室 / 场地」添加实际授课场地。
3. 打开「课程与团队 → 教练团队」，选中门店，点击「新增教练档案」，填写姓名、手机号、擅长科目、证书及有效期，并完成资质审核。
4. 生成本店 **6 位数字团队码**，发给已建档教练。教练在小程序填写相同手机号和团队码，核对后确认加入。
5. 同一教练加入同品牌其他门店时，切到目标门店，使用「添加已有教练」。已绑定微信的教练会获得对应门店身份；尚未绑定的教练可用手机号和目标店团队码加入。

团队码有效 7 天；重置后原码失效。小程序「我的 → 当前业务身份」可切换已有授权，「切换工作门店」可切换门店；原有独立空间和其他身份保留。

### 管理学员与课包

1. 在「学员档案」新建学员，选择归属门店及负责教练。
2. 在「课包与订单」登记已经收到的线下款项，填写课包名称、课时、实收金额和有效期。
3. 适用课程可多选，**默认全部适用，非必填**；转账流水号为选填。独立教练小程序开卡时还可选填上传收款凭证。
4. 学员需要自主预约时，在该学员的「学员邀请码」中生成专属 **8 位数字邀请码**，单独发给本人。邀请码有效 7 天，仅可领取一次。

### 安排课程、预约与消课

1. 在「课程与团队」新增排课计划，选择一种安排方式：**固定循环课**按日期范围、每周上课日和时间发布；**开放可约时间**按教练的空闲区间生成可预约时段。
2. 选择课程、教练和已启用场地，填写人数上限、抵扣课时等信息，预览时间安排后发布。课程会占用实际授课区间的场地时间，并检查冲突。
3. 同时安排多位教练时，每位教练独立计算名额，学员预约时可选择教练。同场多教练授课需要场地支持且明确勾选允许；不勾选时只选一位教练。
4. 学员可在小程序自行预约；工作人员也可在课次名单中为学员代约，门店教练还可从工作台「为学员预约」进入。
5. 学员到课后签到，实际完成教学后再确认消课，并按需填写训练反馈或学员跟进。

预约时先冻结课时，签到不扣课，确认完成教学才扣课；符合取消规则时释放名额与冻结课时。

### 教练：在小程序开展教学

| 使用场景 | 操作方式 |
| --- | --- |
| 独立教练首次使用 | 微信登录后选择「创建自己的独立空间」，填写姓名等信息，无需创建门店 |
| 加入门店 | 在「加入连锁门店」填写管理员登记的手机号和 6 位团队码，核对后确认 |
| 独立空间经营 | 从工作台使用「新建学员」「收款开卡」「安排课程」「场地管理」「为学员预约」「学员跟进」「收款记录」 |
| 门店教练教学 | 从工作台使用「开放可约时间」「为学员预约」「授课安排」「学员跟进」，查看自己的课表和名单 |
| 切换身份或门店 | 在「我的」切换当前业务身份或工作门店，也可点击课程页的门店位置行选择门店 |

页面与功能按当前身份权限展示。

### 学员：绑定档案并自主预约

1. 向教练或管理员获取本人专属的 **8 位学员邀请码**。
2. 微信扫码进入小程序，选择「我是学员，输入邀请码」；已登录的用户可从「我的 → 绑定学员档案」进入。
3. 输入邀请码，预览并核对学员、机构和门店信息，再确认绑定。无需设置账号密码，也无需先创建独立教练空间。
4. 在「我的 → 当前业务身份」选择学员身份。在「课程」中选择门店、日期、课程与教练，选择可用课包并确认预约。
5. 在「预约」查看待上和历史记录，在「课包」查看剩余、冻结及可用课时。

绑定学员档案后，原有教练、独立空间和其他门店身份仍然保留，可随时切换。

### 核对教练账单与结算

1. 后台进入「教练账单」（独立空间显示「授课账单」），按日期、门店和教练查看已完成教学记录。
2. 选择每节固定课酬或消课金额提成，预览并核对金额后生成结算账单。
3. 线下实际结算后，打开账单详情登记「已结算」；可导出授课和账单明细 CSV。

收款、退款与结算功能用于登记已在线下完成的业务，不发起微信支付或自动转账。
